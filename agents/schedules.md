# Scheduled tasks (Cowork > Scheduled). Create each with these prompts. Each runs as its own unattended session with connectors.

## How scheduled runs work (rewritten 5 Oct 2026 after two weeks of silent failures)
Unattended sessions have nobody to approve tool calls, and the sandbox refuses a command that carries a secret and calls an outside API. So scheduled runs follow three rules:
1. NO TOKEN. Never put GH_TOKEN or any secret in a scheduled prompt. The repo is public: read with plain `curl -s https://raw.githubusercontent.com/calum7macleod/dashboards/main/<path>` (no headers). Private repo files are off limits to scheduled runs.
2. NO GITHUB WRITES. A scheduled run never writes a file, a receipt or a handoff. It writes ONE Gmail DRAFT to the connected account's own address (never sent, never to anyone else) - subject `RELAY <AGENT> <YYYY-MM-DD> <AM|PM>` - with the complete result in the body. The owning agent ingests the draft at its next interactive session, writes the files, logs the receipt for the run, deletes the draft.
3. ALWAYS FINISH. If a read is refused, carry on with what the connectors give (Calendar, Gmail) and say in the draft what was skipped. A run that leaves no RELAY draft is a failure - the Manager's Sunday check looks for it.
Every relay body ends with an `issues:` line - anything that failed, one line each - so the owner can log them with `agentkit.py issue`.
