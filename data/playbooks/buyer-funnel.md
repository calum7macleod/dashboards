# BUYER FUNNEL PLAYBOOK (built 22 Jul session - Indian-buyer focus, applies broadly)
Core insight: qualification and standing out must be the SAME act. Lowball = engaged buyer, audition started. Benefit of the doubt at the start; the SYSTEM cuts, not Calum's tone.

1. VOICE NOTE within 5 min: hi + the catch up front (tenanted/handover) + deeds attached + "live in or investment?" -> be the honest one first
2. THE SORT: "Is 2.5 the full budget or where you'd like to land?" Fork A stretch with deeds to real number / Fork B show what money truly buys (or off-plan)
3. QUALIFY AS OWNER'S RULES: cash/finance, timeline, partner on call -> filter without harshness
4. TWO SLOTS + morning 👍 confirm (gate, car, plate) -> kills no-shows + gate mixups
5. NEGOTIATE LEAVING THEM A WIN: hold above floor, shrinking concessions, trade the last step; non-price sweeteners (handover timing, furniture, snagging)
6. CHEAPER-QUOTE COUNTER: "offer form in writing + view today; if real take it; when it's not, same-day message me" -> 1-hour test beats 7-day walkabout
7. QUIET -> PARK -> WIN-BACK: day-2 nudge, day-5 market info, warm week-3 message, zero told-you-so. Burned-by-bait returners = highest trust
8. CLOSE -> 20-sec VIDEO TESTIMONIAL -> the network follows

Rhythm: voice note = info · booked 5-min call = relationship + qualify · phone only for price · text for logistics. Micro-warmth (5 sec) then the catch - never a warm-up act before disclosing the block.
NEVER put "ad price isn't real" in writing - use the true reason (tenancy/handover) only.
