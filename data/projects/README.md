# data/projects/ - the project knowledge base

One file per development. Owned by the Projects agent. Every fact carries a source and a date; "indicative" until a document or register confirms it. Template:

```
# <Developer> - <Project> (<location>)
Status: launched / selling phase N / handed over · Last verified: <date> · Confidence: high/med/low
## Facts - developer, location, product mix, sizes, launch date, handover, service charge, community
## Pricing - from-prices by type, psf, latest known levels, resale premiums
## Payment plan - the shape, dates, entry cost (down + 2% ADM in Abu Dhabi)
## Finance - mortgage routes, banks, LTV, when drawdowns happen
## Calum's position - owns / sold / pitching; what he says on camera; the thesis in one line
## Buyers - who's matched or interested (names only, detail in buyers.json)
## Risks and open questions
## Sources
```
Index of current files is in data/state/projects.md.
