## 1. Canonical buyer rule (the decision - Calum approved queue order 21 Sep)
- stage is the truth. Allowed values: exactly STAGES above. Viewed -> Viewing. Qualifying -> Qualified.
- status is DERIVED, never set by hand: stage Won -> 'Closed Won'; stage Lost -> 'Closed Lost'; anything else -> 'Active'. Three values only.
- closed dates: closedWon (YYYY-MM-DD) when stage goes Won, closedLost when Lost. closedDate is deprecated. Old records with no date stay blank - never invent a date (h0004).
- live = stage not in (Won, Lost). Derive from stage, not status, so a missed status can't hide a lead.
- archive-buyers uses the same shape. Old status values are preserved in a new field lostReason (Inactive | Archived | Bought Elsewhere | Bought) so the Lost/Archived revival view (queue item 5) can use them.

## 2. tools/agentkit.py changes
File is 89 lines; keep the style (one command per elif, terse output).

2a. Safe appends (do first - ten agents now write log/handoffs/issues concurrently)
- Add `def append_line(path, line, msg)`: GET file+sha -> append line -> PUT with sha. On HTTP 409, re-GET and redo the whole thing (up to 3 tries). Never PUT stale text - that overwrites another agent's line.
- Add the same 409 retry-once to putfile for whole-file writes (re-GET sha, PUT again).
- log, handoff, close-handoff, issue, fix all go through append_line or the retrying putfile.

2b. Large files
- getfile: if the metadata response has encoding "none" or size > 1_000_000, re-request the same URL with header Accept: application/vnd.github.raw+json and use the body as the text. Keep the sha from the metadata call.

2c. buyers-index
- live = [x for x in b if x.get("stage") not in ("Won","Lost")]. Same output columns; the stage column already prints stage. Footer stays "-- N live of M".
- Add `buyers-index all` = every record, live first, then Won, then Lost.

2d. buyers-check (new) - the acceptance tool
- Runs on data/buyers.json and data/archive-buyers.json. Prints one line per violation: file|id|buyer|problem. Problems: stage not in STAGES; status != derived(stage); closedDate present (deprecated); stage Won without closedWon or Lost without closedLost (report as "no date" - informational, expected on old records). Footer: "-- N violations, K no-date". Exit 0 always.

2e. owner (new) - private:data/owners/damac-lagoons-owners.json, 3MB, 8,843 rows
- `owner "<query>"` - query must be 3+ chars. Read private:data/owners/README.md FIRST in Claude Code to get the exact field names for unit, owner name, cluster; match case-insensitive substring on those fields. Print one compact line per match, max 50, then "-- N matches (showing 50)" if capped. Never print the whole file. Uses 2b.

2f. issue / issues / fix (new) - data/issues.jsonl, one object per line
- Shape: {"id":"i0001","date","agent","type","what","status":"open"}; when fixed add "fix","fixedBy","fixDate" and set status "fixed".
- `issue <type> "<what>"`: type must be one of tool | data | rule | access | asked, else print the list and exit 1. Sequential ids from line count.
- `issues [open|all] [agent]`: default open. One line each: id|date|agent|type|what. Footer "-- N open".
- `fix <id> "<what changed>"`: sets status fixed, fixedBy=$AGENT, fixDate today, fix text. Print "Done - fixed i0001".
- Create data/issues.jsonl in this change (empty file) so the first append has a sha.
